Play GTA III in your browser

This is an experimental re3 WebAssembly runtime. To begin, select the installation folder from a legally obtained copy of GTA III.

How to play
  1. Click the button below and choose the entire GTA III installation folder, not one individual file.
  2. Wait for the files to load and pass validation, then click Start Engine.
  3. After the engine opens, follow the game menus. Use WASD or the arrow keys for movement and click the game view to enable mouse control.
How it works
The re3 engine runs as WebAssembly in your browser. Your selected files are read locally into a virtual filesystem for the engine. They are not uploaded to this website. A copy may be retained in browser storage for use after a reload.

Only use files you have permission to use. This project does not provide or distribute GTA III game assets and is still experimental. Visit the GTA3-ISO archive or learn how assets are loaded.
